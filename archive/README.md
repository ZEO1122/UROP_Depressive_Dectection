# 과거 기록

- [`plans/`](plans/): 당시의 후보·설계·준비 계획. 현재 실행 상태는 [실험 목록](../experiments/README.md)에서 확인한다.
- [실행 소스 스냅샷](snapshots/pre-reorg-2026-10-04/README.md): 정리 전 51개 Python 소스·테스트의 바이트를 보존한다. 과거 V1/V2의 오류도 당시 기록으로 남긴다.
- [이동 대응표](migration_2026-10-04.json): 과거 경로, 보관/현재 문서 경로, 변경 전후 해시.

현재 개발 코드는 `src/urop/`다. 스냅샷 파일은 수정하지 않는다. 과거 실행을 감사하거나 명령을 실행할 때는 [legacy 경로](../docs/reproducibility.md)를 사용한다. 새 실행의 설정·코드를 과거 frozen 기록에 덮어써서 일치하는 것처럼 만들지 않는다.

전체 정리 전 코드·문서·테스트 백업과 검사 결과는 로컬 `Data/repo_reorg_2026-10-04/`에 있다. 원본 데이터·가중치·전사·예측과 기존 가상환경·PDF 출력은 현재 위치에 보존했다.
