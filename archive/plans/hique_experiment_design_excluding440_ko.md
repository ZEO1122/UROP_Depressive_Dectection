## 1. 목적과 근거

질문: 논문에 명시된 질문 계층 및 A/V/T 특징을 구현한 HiQuE가 DAIC-WOZ의 PHQ 이진 라벨을 얼마나 예측하며, 질문 계층과 모달리티 결합이 어떤 영향을 주는가?

목표 수치에 맞춘 튜닝이 아니라, 명세·입력·평가의 충실도를 확인한다. 440 제외만으로도 원 논문과 표본 조건이 다르므로 0.79의 동일 조건 재현이라고 주장하지 않는다. 기존 184명 변형 실험은 별도 기록으로 보존한다.

- 논문: https://arxiv.org/abs/2408.03648v1 (§3, §4.3–4.7, §5, §6)
- 코드: https://github.com/JuHo-Jung/HiQuE (검토한 commit: 24c553bf2666b442ae5b0e3490b998a5d4493559)
- 공식 설명서: https://dcapswoz.ict.usc.edu/wp-content/uploads/2022/02/DAICWOZDepression_Documentation.pdf

근거 우선순위: 논문에 명시된 실험 조건 → 저자에게 확인된 실행 자료 → 논문과 충돌하지 않는 공개 코드 → 명시적으로 이름 붙인 재구현 가정. 저자에게 확인되지 않은 가정을 '원래 방법'이라고 부르지 않는다. 연락은 별도 사용자 지시 없이 보내지 않는다.

## 2. 데이터

| 분할 | 목표 인원 | 규칙 |
|---|---:|---|
| Train | 107 | 공식 ID 유지 |
| Dev | 34 | 공식 35명 중 440만 제외 |
| Test | 47 | 공식 ID 유지, 300 포함 |
| 합계 | 188 | 참가자 단위 분리 |

- 440 ZIP은 입력 목록에서 명시적으로 제외한다. 부분 복구 자료도 이번 실험에는 넣지 않는다.
- 300은 원래 test 참가자로 복원한다. 이전 사례 노출은 기록하되 임의로 sample-specific 처리를 하지 않는다.
- 451/458/480은 공식 설명서상 Ellie 전사만 누락됐다. 제외를 확정하지 않고 공개 Whisper 경로의 입력 생성 가능성을 먼저 검사한다. 참가자 마이크에는 Ellie가 작게 섞일 수 있으므로 질문이 모두 복원된다고 가정하지 않는다.
- 402는 실제 존재하는 영상 구간만 사용하며, 뒤쪽 영상 결측으로 음성·텍스트까지 제거하지 않는다.
- 409는 제공 binary를 유지하고 score와의 불일치를 기록한다. 다른 라벨 정책을 사후 적용하지 않는다.
- Test 라벨은 현재 사용자 제공 CSV를 쓰며 배포 출처 확인 범위를 밝힌다.

188명은 목표 cohort이며 188명 모두 유효 입력을 확보했다는 선언이 아니다. 451/458/480의 질문 입력이 실제로 확보되지 않으면 full188 질문 기반 평가를 완료했다고 주장할 수 없다. 이때 학습 전에 적격성 보고서에서 사유를 확정하고, 대안은 해당 3명도 제외한 185명(107/32/46)의 '질문 입력 가용 cohort'로 별도 명명한다. 모두 0인 입력이나 추측한 질문으로 인원을 맞추지 않는다. 모든 비교 모델은 최종 확정된 동일 cohort를 사용한다.

## 3. 전사·질문 대응

1. 공개 코드 경로는 Whisper `base` 로컬 전사, 물음표로 끝나는 segment를 Ellie로 분류, 연속 동일 화자 병합이다. 이 규칙은 화자 인식 정답이 아니므로 오류율과 한계를 기록한다.
2. 원 공개 경로를 추적하는 주 실행에서는 동일 전사 방법을 전체 cohort에 일관되게 적용한다. 문제가 있는 참가자에게만 다른 전사기를 적용하지 않는다. 모델 revision/디코딩 기본값/패키지 버전을 추출 전에 고정한다.
3. 제공 전사는 train에서 화자·질문 경계 확인용으로 활용한다. 제공 전사를 입력으로 쓰는 실험은 별도 민감도 분석으로 구분한다. ASR 품질 개선을 test 결과에 맞춰 수행하지 않는다.
4. 85개 질문 코드북을 논문 부록과 공개 코드가 요구하는 schema(topic_idx/topic/question/type)에 맞춘다. 실제 참조 CSV가 공개되지 않은 부분은 복원 근거를 기록한다.
5. 공개 `similarity.py`의 BERTScore argmax 대응을 기준으로 한다. 기존 자체 RoBERTa token F1 및 0.75 cutoff는 승계하지 않는다. BERTScore 실제 model/layer/hash는 설치한 버전의 기본 해석을 확인해 고정하며, 사용되지 않는 bert-base 객체를 그 모델로 오인하지 않는다.
6. 질문 시작/종료, 응답 시작/종료, 원문 행, 매핑 근거, 반복·후속 여부를 추적 가능하게 저장한다. 원 코드의 단순 다음 행 접근과 무조건 덮어쓰기를 검증 없이 재사용하지 않는다.

## 4. 계층 관계: 본학습 전 필수 확인

논문 §4.3은 후속 질문에 앞선 질문의 topic ID를 부여한다고 설명한다. 공개 모델의 PositionEmbedding은 고정 위치 배열을 쓰며, 공개 파이프라인만으로 논문의 관계가 최종 tensor에 반영되는 전체 과정은 확인되지 않았다.

따라서 우선 사건별 `(question_id, question_type, previous_question_id, parent_topic_id, followup_depth, answer_span)` 대응표를 만들고, 다음 예시를 통과시킨다.

- 주질문 → 후속 질문 → 후속 질문의 연쇄.
- 동일한 일반 후속 질문이 서로 다른 주제 뒤에 나오는 경우.
- 주제 전환, 같은 질문 재등장, 주질문 없는 후속 질문.
- 해당 관계가 메타데이터에만 남지 않고 실제 입력/position에 반영됨.

동일 topic의 반복 응답 집계, parent ID와 고정85 슬롯의 관계, 위치 임베딩 연산은 저자 예시·원 intermediate가 있으면 그것으로 확정한다. 없으면 합리적 해석을 명시한 별도 '논문 명세 기반 계층 재구현'으로 명명하고, 연산식·배열 예시를 본학습 전에 고정한다. parent embedding을 임의로 추가하고 원 구조와 동일하다고 주장하지 않는다. 이 명세가 확정되기 전에는 계층 모델 본학습을 시작하지 않는다.

## 5. 특징과 결측

| 모달리티 | 기본 입력 | 근거·확정할 세부사항 |
|---|---|---|
| A | 85×88 | openSMILE eGeMAPSv02 functionals; 코드와 일치. 버전과 특징 순서 고정 |
| V | 85×272 | 논문 CLNF 68개 x/y, 1fps 평균·분산. 공개 VGG 경로 대신 논문 우선 |
| T | 85×768 | 논문 RoBERTa 마지막 layer CLS. 공개 BERT pooled output 대신 논문 우선 |

- RoBERTa-base를 frozen으로 사용하는 선택은 현재 재구현 가정이다. checkpoint revision, tokenizer, 최대길이와 초과 응답 정책을 본학습 전에 기록하고 원 저자 설정으로 단정하지 않는다.
- 시각 표본화의 시간 원점·좌표계·분산 ddof, Q-A 전체인지 answer-only인지 모달리티별 구간 정의를 명세화한다. 원문과 코드에서 불명확한 구간 정책은 동일한 것으로 가정하지 않는다.
- 질문 부재는 해당 슬롯의 0벡터로 표현한다. 모달리티별 결측은 별도로 유지한다. 기존 A∩V∩T 공통 mask로 유효한 다른 정보를 지우지 않는다.
- 기존 임의 품질 cutoff·train-only 표준화도 원 경로의 근거가 없으면 주 설정에 자동 적용하지 않는다. 정규화를 추가할 경우 train에서만 fit하고 별도 조건으로 명명한다.
- NaN·범위 밖 시각·깨진 구간은 오류 감사표에 남긴다. 손상 값을 정상 관측값으로 취급하지 않는다.
- 모든 특징의 ID/질문축/시간 경계가 일치하는지 학습 전에 검사한다. 중간 파일 hash와 실행 소스를 보관한다.

## 6. 모델과 학습

- 논문 서술의 question-aware → cross-modal attention → pooling/classification 구조를 공개 hique()와 대조한다.
- 공개 코드의 4차원 embedding/1 head, 두 self-attention block 및 세 cross-modal branch를 구조 대조표에 기록한다. 논문의 tensor 설명과 충돌하는 지점은 별도 확인한다.
- loader의 참가자 누적, 잘못된 결측 차원, tuple 반환 및 직렬화/환경 호환 오류는 최소 수정한다. 모델링 변경과 오류 수정을 분리한 patch를 남긴다.
- 학습값: 100epochs, batch8, lr0.0002, dropout0.5. Epoch은 논문을 따라 공개 CLI 기본50을 덮어쓴다.
- 공개 compile 경로를 따라 Adam/categorical cross-entropy, 최저 dev loss checkpoint 및 softmax argmax를 사용한다. Adam 기본 인수는 환경과 함께 기록한다.
- Train 양성만 3배: 원본+두 복사본, 각 복사본에서 85개 중10개 질문을 A/V/T 동기 masking한다. 증강본은 split을 넘지 않는다. 매 epoch 재생성 여부는 저자 설정 미확정이며, 없으면 1회 생성 가정으로 사전 고정한다.
- 공개 CLI seed42를 기준 실행으로 두되 원 Table1 seed라고 단정하지 않는다. 추가 seed13/23/37/79는 안정성 분석이다. 최고 seed를 골라 대표하지 않는다.
- 마지막 batch 처리와 steps_per_epoch는 공개 코드의 floor 지정 동작을 버전별 확인하고, 실제 sample 노출 수를 기록한다. 조용히 다른 학습량으로 바꾸지 않는다.

## 7. 실험 순서와 비교

첫 단계는 전체7조건×5seed 재실행이 아니다.

1. 합성 대화 및 train 소수 사례에서 질문 계층·시간 대응·feature/shape 검증. 작은 train subset 과적합과 저장/복원 검사.
2. 계층 명세 확정 후 AVT 기준 실행(seed42). train/dev로만 실행 오류를 진단한다.
3. 동일 전처리·cohort에서 AVT의 계층 제거 조건과 T 단독 조건을 실행한다. 계층 제거 때 입력 내용·학습 예산을 맞춰 효과를 분리한다. 정보 집계까지 바뀌면 순수 position ablation이라고 부르지 않는다.
4. 위3조건의 나머지4seed: 계획상 핵심15회 학습. 그 후 필요하면 나머지 모달리티 조건을 확장 분석으로 추가한다.
5. Test는 사전 고정한 모든 핵심 run 완료 후 일괄 평가한다. 원 논문과 직접 비교할 기준 seed 결과와 seed별 평균±SD를 별도로 제시한다.

추가로 질문 등장 여부만 쓰는 대조군과 train 다수 class 대조군을 같은 cohort에서 보고한다. 이 대조군은 원 논문 재현 항목이 아니라 입력 경로와 불균형을 확인하는 진단이다.

## 8. 평가·결론

- 주지표: 참가자 단위 Macro-F1. 논문 Table1과 함께 macro P/R, weighted P/R/F1, G-mean(원 정의 확인)을 보고한다.
- 보조지표: 양성 F1, sensitivity/specificity, AUROC, confusion matrix.
- 사전 주요 비교: 계층 AVT − 계층 제거 AVT. 보조 비교: 계층 AVT − 계층 T.
- 시드별 차이의 평균에 대해 참가자를 paired bootstrap 2,000회 재표집하여 CI를 구한다. 매 재표집에서 각 seed의 F1을 계산한 뒤 차이를 평균한다. 확률 ensemble과 혼동하지 않는다. 고정된 훈련 run에서의 test 표본 불확실성으로 한정한다.
- 성능 원인 분석은 train/dev에서 수행한다. 이미 test45와 공개 사례를 확인했으므로 새 실행의 test47도 완전히 미노출된 평가라고 주장하지 않는다. 임의 재분할로 이를 해결했다고 보지 않는다.
- 논문값0.79, 기준seed값, 5seed 평균, 표본 수, 가정/편차, 사용 가능한 입력률을 한 표에 기록한다. 0.79 달성을 성공 기준으로 삼지 않는다.

## 9. 실행 전 승인 조건이 아닌 기술적 통과 조건

- 440 제외 ID 목록 및 실제 적격 cohort 확정.
- 451/458/480의 질문 구간 확보 가능 여부 확인; 가용성으로만 cohort 결정.
- 계층 ID가 실제 입력에 연결되는 연산·예시 확정.
- 비공개 중간 CSV 대체 방법, checkpoint·버전·구간 정책·결측 및 반복 처리 가정 문서화.
- 데이터/코드 검증 통과 후 configuration hash 고정.

미확정 사항이 남으면 전체 작업을 멈추는 대신 명세 조사·train 예시 검증·환경 준비를 진행할 수 있다. 다만 미확정 계층 모델을 원 논문 그대로라고 보고하거나, 유효 입력 검증 없이188명을 모두 사용했다고 보고하지 않는다.

새 실행 산출물은 `Data/hique_reproduction_excluding440/`로 분리할 예정이며 기존 실험 폴더는 보존한다. 이번 요청에서는 설계 문서만 작성했다.
