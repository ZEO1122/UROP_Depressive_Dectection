# LLM API 없이 세 관심 방향을 연결하는 실험 설계

> 보존된 과거 계획이다. 실행 여부와 실제 조건은 [실험 목록](../../experiments/README.md)의 결과 기록을 우선한다.

작성일: 2026-09-26 · 개정일: 2026-09-27 (전체 다운로드 점검 반영). 상태: **검토용 설계안, 실행·성능 검증 미수행**. 연구 주제 최종 확정이나 Notion 작업 상태 변경을 뜻하지 않는다.

> 실행 전 선행연구 검토(2026-09-27): 삭제·무관 삭제·중복 근거 보존은 SufficientFacts(TACL 2022)와 직접 겹친다. 임상 지식·평가 불가능 판단 및 멀티모달 masking·사람 평가도 기존 연구가 있다. 아래는 새 알고리즘의 확정 설계가 아닌 적용·검증 파일럿으로 읽는다. [중복 검토와 실행 전 권고](../../docs/literature/evidence_experiment_prior_art.md).

## 1. 제안하는 실험 하나

**제목: 임상 맥락을 선택적으로 가렸을 때, 지식 기반 특징과 비언어 관측은 우울 증상 근거의 충분성 판단을 개선하는가?**

DAIC-WOZ의 동일 면담으로 원본·필수정보 삭제·무관정보 삭제·중복근거 보존 조건을 만든다. 작은 로컬 분류기가 증상 보고와 기간·빈도·기능 정보의 유무를 구분하도록 학습하고, 임상 지식 특징(K), 담화 맥락(D), 음성(A), 시각 특징(V)의 추가 효과를 비교한다.

핵심 산출물은 최고 PHQ 점수가 아니라 **입력에서 실제로 확인 가능한 것과 확인할 수 없는 것을 구분하는 작은 평가셋 및 baseline**이다. API, 생성형 LLM, LLM annotation, LLM judge를 사용하지 않는다. TF-IDF·규칙 특징·로지스틱 회귀와 기존 시계열 요약으로 CPU 실행을 목표로 한다. 실행 시간은 아직 측정하지 않았다.

| Notion의 세 방향 | 이 실험에서 검증하는 부분 | 검증하지 못하는 부분 |
|---|---|---|
| 증상 은폐와 거짓 반응 | 증상 관련 정보가 관측되지 않을 때 부재·명시적 부인·정보 부족을 혼동하는지 | 의도적 은폐, 거짓말, 수치심의 탐지 |
| 임상 지식과 면담 맥락 | 임상 기준을 반영한 특징과 앞뒤 QA가 근거 판별에 주는 효과 | LLM의 지식 활용 능력 자체 |
| 멀티모달 근거 충분성과 과잉추론 | A/V 추가가 정확한 근거 판별을 돕는지, 없는 기간·빈도·기능 정보를 있다고 판정하게 하는지 | 얼굴·목소리에서 숨겨진 진실이나 진단을 복원했다는 주장 |

첫 번째 방향과의 연결은 **은폐 탐지의 선행 문제인 불완전 관측 처리**이다. 삭제는 관측 정보에 대한 시스템 실험이며 실제 사람이 숨기는 행동의 재현이 아니다. 세 주제를 같은 강도로 직접 검증한다고 주장하지 않는다.

## 3. 연구 질문과 사전 가설

**RQ:** 관측 가능한 근거가 달라졌을 때, 모델은 해당 정보의 판단만 적절히 바꾸고 나머지는 유지하는가? K/D는 이를 돕는가? A/V는 어떤 판정에 유익하거나 유해한가?

- H1: 같은 입력·출력 과제에서 K 특징을 추가하면 단순 단어 통계보다 정보 부족과 명시적 부인을 더 잘 구분한다.
- H2: D에서만 확인되는 근거를 제공하면 해당 slot의 판단이 정답 방향으로 바뀐다. 무관한 맥락 변화에는 판단이 유지된다.
- H3: A/V의 추가 효과는 측정 대상별로 다르다. **언어 근거가 전부 없어진 기간·빈도·일상 기능 정보는 A/V를 추가해도 확인된 사실이 되지 않는다.** A/V가 평균 성능을 높인다고 미리 가정하지 않는다.

평가 정보의 기간·경과·기능을 별도로 다루는 근거는 [NICE NG222 1.2.6–1.2.7](https://www.nice.org.uk/guidance/ng222/chapter/Recommendations)다. 이 연구의 slot schema 자체는 공식 진단도구가 아니라 연구용 구조다.

## 4. 분석 단위와 사람이 만드는 정답

**범위:** 수면 문제와 흥미·즐거움 저하 두 영역. 세 관심 주제와 두 증상 영역은 다른 구분이다. 먼저 두 영역의 자료량과 일치도를 보고 넓힌다.

**단위:** 참가자 × 증상 영역 × anchor 응답. 최소 한 QA 단위를 유지한다. 같은 질문의 연속된 Participant 전사행을 합치는 규칙을 사전에 정하고, 1개 행을 임의의 완결 문장으로 가정하지 않는다.

- U: anchor 참가자 응답만.
- D: anchor 질문 및 앞뒤 각 두 QA 단위. 경계를 넘는 것은 포함하지 않는다. 전체 면담 검색이나 gold span을 이용한 oracle retrieval은 하지 않는다.
- 후보 선정: train에서 정한 질문/증상 사전의 후보와 무작위 비후보 QA를 함께 주석한다. 후보만 평가해서 recall이 높아 보이는 것을 막는다. 개발 pilot은 참가자당 약 8–12 anchor를 목표로 하되 실제 적격 건수와 분포를 먼저 보고한다. 확정 표본 수나 검정력 계산값이 아니다.

두 명이 PHQ 점수와 모델 예측을 가리고 독립 주석한다. 지침은 임상 전문가에게 검토받고 불일치 조정을 계획한다. 협력이 없으면 임상적으로 검증된 assessment gold가 아닌 **연구자 주석의 정보 추출 pilot**으로 한정한다.

| 정답 축 | 값·정의 |
|---|---|
| 보고 근거 상태 | 지지 / 명시적 부인 / 판단할 근거 없음 / 상충 |
| 현재성·경험 주체 | 현재·과거·모호함, 본인·타인·가정 등 |
| 기간 / 빈도 / 기능 slot | 특정 증상·경험 주체·시점에 연결된 명시적 정보가 있음 / 모호·미언급 / 서로 충돌 |
| 출처 | participant 발화 offset·turn ID·시간구간, 필요한 질문과의 연결 |
| 관측된 부족 이유 | 질문 없음, 관련 질문에 명확한 답 없음, 구체성 부족, 명시적 답변 거절, 데이터 손실 등; 의도는 주석하지 않음 |

예: “잠을 잘 못 잔다”는 수면 호소의 지지 근거지만 기간·빈도·기능은 미확인일 수 있다. “매일은 아니다”는 빈도에 관한 부분 정보이며, 실제 빈도를 특정하기에 충분한지 별도 지침이 필요하다. “잘 잔다”와 수면 미언급은 다르다. 시점이 다른 두 진술은 자동으로 상충이 되지 않는다.

**정답은 제시된 정보에 상대적이다.** U에 없고 D에만 있는 정보는 U 조건에서는 unknown, D 조건에서는 확인 가능할 수 있다. 완전 면담의 정답을 모든 입력에 복사하지 않는다. 전체 기록으로 출처를 표시한 뒤 각 입력 뷰에서 실제로 남는 근거를 독립 검토한다. 따라서 U와 D의 전체 F1 차이만으로 이해 능력 향상을 주장하지 않고, 공통 판정 가능 subset 및 사전 지정한 전환 정확도를 함께 보고한다.

주석 일치도는 축별 Cohen’s kappa와 단순 일치율, 각 class 건수, span overlap을 함께 보고한다. 희소한 상충 class의 F1을 숨기거나 강제로 다른 class로 합치지 않는다. 지침을 바꿨다면 개발분을 재주석하고 시험분을 열기 전에 고정한다.

## 5. API 없는 모델과 조건

**공통 모델:** TF-IDF word 1–2 gram 및 고정 수치 특징 → L2 logistic regression. 보고 상태는 다중 class head, 각 slot은 동일 형태의 별도 head로 구현한다. 원본 영어를 사용하며 번역 API나 자동 생성된 증상 라벨을 쓰지 않는다.

**K의 구현:** 검토된 기준표를 증상 표현, 부정 범위, 과거/현재, 경험 주체, 기간 단위, 빈도 표현, 기능 관련 표현의 사전·규칙 특징으로 구현한다. 예컨대 기간 단어가 질문자 말에만 있는지, 참가자 응답과 연결되는지에 대한 자동 특징이다. 사람이 해당 사례의 정답을 입력하는 것이 아니다. 고정 기준표를 TF-IDF 입력 끝에 붙이는 것만으로 지식 주입 효과를 주장하지 않는다.

K는 지식에 기반한 **특징 설계**이다. 효과가 나와도 “LLM이 DSM을 이해했다”는 증거는 아니다. K가 예측을 강제로 unknown으로 덮어쓰는 규칙은 주 비교에서 사용하지 않는다. 그렇게 하면 부족 판단이 좋아진 것이 구현 규칙의 자명한 결과가 될 수 있다.

| 조건 | 입력 | 비교 목적 |
|---|---|---|
| B0 | U | 국소 어휘 baseline |
| B1 | U + K(U) | 국소 입력에서 지식 특징 효과 |
| B2 | U + D | 대화 맥락 효과 |
| B3 | U + D + K(U,D) | 같은 맥락에서 K 추가 효과 |
| B4 | B3 + A | 음성 특징 추가 |
| B5 | B3 + V | 시각 특징 추가 |
| B6 | B3 + A + V | 결합 효과 |

출력 형식과 classifier 종류는 동일하다. TF-IDF와 모든 수치 전처리는 학습 fold 내부에서 fit한다. 화자는 분리된 text channel로 인코딩하고 질문 내용을 participant 보고로 합치지 않는다. 동일 후보 및 입력 보유 cohort를 사용한다.

- A: anchor 응답의 로그 RMS 중앙값·변동, 확인된 voiced F0 중앙값·IQR, utterance duration, 같은 응답 내 전사 구간 사이 gap 등 소수 요약. transcript gap은 실제 VAD 침묵과 구분한다. 질문 종료 기준 latency를 사용한다면 D 의존 특징임을 별도 기록한다.
- V: 유효 프레임의 AU 강도 요약, head rotation 변동, head-relative gaze 변동. 대규모 HOG/신경망은 첫 실험에서 제외한다. AU를 슬픔·수치심·가짜 미소의 정답으로 치환하지 않는다.
- 각 feature block 차원 상한과 목록을 train pilot에서 고정한다. 큰 시계열 모델을 새로 학습하지 않는다.
- 기초 대조군: train 다수 class, 항상 unknown, 질문만 입력한 모델. 항상 unknown은 부족 탐지에 좋아 보여도 충분 정보에서 실패해야 한다.

질문만으로 PHQ 분류가 잘되는 shortcut은 이미 [Burdisso et al., 2024](https://aclanthology.org/2024.clinicalnlp-1.8/)가 다뤘다. 이 실험의 질문-only는 같은 현상을 점검하는 대조군이지 독립 신규 기여가 아니다. 질문-only가 정보 충분성을 어느 정도 예측하는 것 자체를 무조건 부당한 누수로 규정하지 않는다.

|---|---|---|
| O: 원본 | 변경 없음 | 기준 |
| E: 필수 근거 삭제 | 기간·빈도·기능 중 한 slot을 명확하게 하던 유일한 근거 제거 | 해당 slot만 unknown으로 전환; 남은 증상 호소는 유지 |
| R: 길이 대조 | 같은 수의 turn, 유사한 단어 수·시간 길이의 무관 정보 제거 | 해당 slot 유지 |
| S: 중복 근거 보존 | 근거 하나를 삭제하되 같은 정보의 독립 근거가 입력에 남음 | 해당 slot 유지 |

핵심 규칙:

1. 선택한 입력 전체의 중복 근거를 확인한다. 다른 발화에 정보가 남으면 E가 아니다. S는 실제 중복 근거가 있는 사례에만 적용하고 문장을 복제해 만들지 않는다.
2. 최소 pilot은 anchor 자체보다 주변 맥락에 있는 unique support를 제거해 anchor A/V를 동일하게 유지한다. 증상 호소와 기간이 같은 한 발화에만 있어 분리할 수 없는 사례는 이 주 비교에서 제외하고 제외 수를 기록한다.
3. 전사만 지우고 같은 말을 WAV로 들려주면 정보 삭제가 아니다. 삭제 turn의 모든 입력 경로(텍스트, 음성, 시각, 요약 cache)에서 대응 구간을 제거한다. 추가하는 A/V는 남아 있는 anchor의 비언어 요약이다.
4. 영(0) 값으로 채워 침묵처럼 보이게 하지 않는다. 삭제 위치·조건명·원래 길이·mask 정답은 모델 feature로 주지 않는다. 시간 간격은 삭제부를 가로질러 계산하지 않는다.
5. R는 E와 같은 사례에서 만드며, turn 수 일치와 단어 수·시간 길이 차이 10% 이내를 기본 목표로 한다. 적합한 R가 없으면 E–R 주 분석에서 제외한다. 허용 범위는 pilot에서 정한 후 시험 전에 고정한다.
6. 전체 원본 성능과 O/E/R 공통 적격 subset 성능을 별도 보고한다. S는 중복 근거 subset이라 모집단이 달라 별도 분석한다.
7. 재주석자는 가능하면 조작 종류와 원본을 보지 않고 제시된 뷰만 평가한다. 정보삭제 manifest를 정답으로 무검토 복사하지 않는다.

이 조작으로 얻는 것은 **누락에 대한 반응**이다. 실제 은폐율·기만 탐지 F1을 계산하지 않는다.

## 7. 주평가와 해석 규칙

**주 지표:** 기간·빈도·기능 slot의 정보 상태 macro-F1. 같은 입력 조건의 B3−B2를 1차 비교로 지정한다. K와 D의 2×2 구조에서는 B1−B0, B3−B2로 K 효과를, D가 추가하는 근거에 대해서는 정답 전환 정확도를 본다.

**함께 반드시 보고할 오류:**

- 근거 없는 확인률 = gold가 모호·미언급인데 정보가 확인됐다고 출력한 건수 / gold 모호·미언급 건수.
- 불필요한 보류율 = gold가 명시적 정보 있음인데 unknown으로 출력한 건수 / gold 명시적 정보 있음 건수.
- 보고 상태 macro-F1 및 class별 recall: 미언급과 부인을 구별하는지.
- E 전환 정확도: 원본에서 충분했고 삭제로 불충분해진 slot을 올바르게 바꾼 비율.
- R/S 유지 정확도, 삭제와 무관한 다른 slot의 보존율.

상충 class는 위 두 오류율의 분모에서 제외하고 class별 F1과 상충을 단일 정보로 확정한 오류율을 별도 보고한다. 분모가 0인 지표는 0점이 아니라 계산 불가로 표시한다.

E 전환은 각 입력 조건에서 실제로 gold가 충분→불충분으로 바뀌는 쌍에만 계산한다. 주변 D를 삭제하는 주 실험에서는 B2–B6가 해당하며, 입력이 그대로인 U-only B0/B1에는 전환을 요구하지 않고 불변성만 평가한다. 적격 쌍에서 `O 정답 AND E 정답`인 비율과, O를 맞힌 쌍 안의 전환율을 둘 다 보고한다. 처음부터 계속 unknown인 모델이 성공으로 보이지 않게 한다.

A/V는 B4/B5/B6 각각을 B3와 비교한다. F1 이득과 위 두 오류율을 같이 제시한다. “무해함”은 유의차가 없다는 것만으로 입증하지 않는다. 시험 전에 정한 허용 악화 폭이 없다면 비열등성을 주장하지 않고 차이와 신뢰구간만 보고한다.

출력은 구조화된 분류이므로 이 오류를 **LLM hallucination 발생률**이라고 부르지 않는다. 자연어 근거 생성, 인과 설명 생성, 임상 효용을 평가한 것도 아니다.

threshold 기반 추가 보류를 시험한다면 모든 조건에 같은 탐색 예산을 주고 개발분에서만 threshold를 정한다. risk–coverage 및 동일 coverage에서의 오류를 보조 보고한다. semantic unknown과 낮은 모델 확신에 따른 abstain은 출력 필드를 분리한다.

비교는 참가자 단위 paired bootstrap 2,000회로 95% CI를 계산하고, 한 사람의 모든 anchor·변형을 같이 재표집한다. 참가자별 평균 오류도 제시해 발화 많은 사람이 지배하지 않게 한다. 희소 class가 없는 재표집의 처리와 횟수를 명시한다. A/V의 여러 비교는 탐색적으로 표기하거나 사전 지정한 다중비교 보정을 사용한다.

## 8. 확보된 전체 corpus를 사용하는 본실험

이제 자료 확보 때문에 12명 학습 pilot에 머물 필요는 없다. **공식 분할을 유지한 정상 train 106명 / dev 34명 / test 46명**을 기반으로 본실험을 설계한다. 424·426·440을 보완하면 공식 107/35/47 전체가 준비된다. 단, 원자료 확보와 독립 gold 확보는 다르므로 학습·평가 시작 전에 주석과 품질 cohort를 확정한다.

### 8.1 먼저 train 20명으로 지침을 고정

- 정상 ZIP을 가진 공식 train에서 고정 seed 42로 20명을 선택한다. 기술적 입력 가용성을 먼저 검사하며 모델 결과를 보고 사람을 선택하지 않는다. 지침 개발에서 PHQ를 주석자에게 제공하지 않는다.
- 각 참가자 8–12개 anchor를 작업량 가정으로 삼아 두 명이 독립 주석한다. 증상 사전 후보와 무작위 비후보를 예를 들어 1:1로 표집하는 규칙을 train pilot에서 정하고 고정한다. 이를 자연 면담 전체의 prevalence나 전체 recall로 해석하지 않는다.
- 영역·slot별로 후보 수 → 명시적 근거 수 → 주변 D의 유일 근거 수 → anchor를 보존하며 삭제 가능한 수 → R 매칭 가능한 수를 집계한다. 각 단계의 **참가자 수와 사례 수를 모두** 센다.
- 지침, K 규칙, QA 결합·후속 질문 처리, 매칭 허용 범위를 동결한다. 지침이 바뀌면 pilot 20명도 최종 지침으로 재주석하고 train에 포함한다. 개발에 사용한 참가자의 CV 수치는 독립 검증 성능이 아니다.

### 8.2 전체 주석과 split 사용

| 분할 | 보유 인원 | 용도 |
|---|---:|---|
| Train | 106 (426 복구 후 107) | 20명 지침 pilot 포함; 특징 설계·학습·참가자별 CV |
| Dev | 34 (440 복구 후 35) | 고정 지침 적용, 제한된 모델 선택·필요시 calibration/보류 threshold |
| Test | 46 | 424 미보유; 사전 노출과 품질 제외를 반영한 최종 평가 |

참가자당 원본 8–12 anchor라면 정상 186명 기준 **1,488–2,232개 원본**, 두 평가자 기준 **2,976–4,464회 원본 주석**이 작업량 상한 예시다. 아래 D 누락·사전 노출 제외 후 현재 주실험의 참가자 상한은 182명이므로 **1,456–2,184개 원본, 2,912–4,368회 원본 주석**을 우선 자원 계획으로 잡는다. 변형본 독립 검토·조정은 추가다. 누락·손상 세 파일을 모두 보완하면 주실험 상한 185명, 원본 1,480–2,220개가 된다. 실제 적격 수는 이 계산보다 작을 수 있으며 증상별 슬롯 수나 변형 수를 독립 표본 수로 세지 않는다.

임상 협력이 없다면 이중 연구자 주석으로 정보 추출 연구는 진행할 수 있으나, 임상적으로 검증된 평가 도구로 표현하지 않는다. 인력이 부족하면 시험 결과를 보기 전에 train/dev/test별 주석 subset을 무작위로 고정하고, 사용한 실제 N을 보고한다. 정상 원자료 186명이 있다고 gold 186명이 준비됐다고 쓰지 않는다.

### 8.3 사전 노출과 품질 cohort

- **300:** 기존 Week1 자료에서 세부 내용·라벨이 사례로 사용됐다. 학습으로 이동하지 않고 주평가에서 제외한 민감도 통제 cohort를 사전 지정한다. 300 제외만 반영하면 현재 test 상한은 **45명**이다. 아래 면접자 전사 없는 480도 제외하면 주평가 test 상한은 **44명**, 424 보완 후 **45명**이다. 이미 다른 test 사례도 설계에 사용했다면 노출 목록을 추가한다. 가용 공식 test 전체 결과는 사전 노출 포함 보조 결과로 분리한다.
- **451·458·480:** 배포 설명서의 면접자 전사 누락을 실제 전체 transcript에서도 확인했다(Participant만 존재). D 기반 B0–B6 공통 비교에서 451·458(dev), 480(test)을 제외한다. 질문을 추측해 복원하지 않는다. U-only 보조 분석은 별도 분할 규칙과 cohort로 보고한다.
- **402:** 실제 AU/pose/gaze 마지막 timestamp는 **833.267초**, WAV는 **955.49875초**, 전사 마지막은 **972.251초**다. 오디오 끝을 넘는 전사 3행은 모두 Ellie다. 시각 비교는 833.267초 이내의 실제 유효 프레임을 가진 anchor로 제한하고, D에 필요한 음성의 가용성도 별도 확인한다. 정상 CRC라도 시간 정렬 품질이 보장되는 것은 아니다. 후반을 0으로 채우지 않는다.
- **373·444:** 설명서의 기술 중단 구간을 실제 timeline과 대조해 해당 구간을 제외한다. 사람 전체를 자동 삭제하지 않는다.
- B0–B6의 종합 표는 T/D/A/V가 모두 유효한 동일 anchor·참가자 집합에서 만든다. 더 넓은 text-only cohort 성능은 별도 표로 보고한다. 전체 파일 존재와 학습에 유효한 프레임 존재를 구분한다.

현재 사전 제외만 적용한 주실험 상한은 **train 106 / dev 32 / test 44 = 182명**이다. 세 파일 복구 후에는 **107 / 33 / 45 = 185명**이다. 이는 정상 파일·D·사전 노출 조건의 상한이며, 증상 anchor·정보삭제 적격성·프레임 품질을 적용한 최종 N은 더 작아질 수 있다. 402의 시각 잘림은 구간별 제외이므로 이 단계에서 참가자 전체를 빼지 않는다.

### 8.4 학습과 통계

- TF-IDF·scaler·imputer는 train fold 안에서 학습한다. hyperparameter C ∈ {0.1, 1, 10}을 participant-group 5-fold CV로 비교하고 조건별 탐색 예산을 동일하게 둔다.
- Dev의 모델 선택·calibration 범위를 사전에 기록한다. test의 gold·결과로 모델, K, 제외·매칭 규칙을 조정하지 않는다. test 주석은 고정 지침으로 수행하고 정답은 모델 개발자에게 봉인한다.
- 원본과 모든 변형·모달리티는 원 참가자의 공식 split을 따른다. PHQ 점수·ID·파일명·mask 종류는 입력에서 제외한다.
- 주 비교는 B3−B2, B4/B5/B6의 추가 효과는 보조 비교로 유지한다. 총 186명이 아니라 **실제 적격 test 참가자**를 단위로 paired bootstrap CI를 계산한다.
- 주석 gold의 class 분포·삭제 적격률은 아직 모른다. 데이터가 늘었다는 이유만으로 충분한 검정력을 주장하지 않는다. train pilot의 분산과 적격률로 최소 의미 효과에 대한 정밀도/검정력을 산정하고 분석계획을 동결한다. E/R 쌍이 소수 참가자에 집중되면 그 분석을 탐색 결과로 한정한다.
- 삭제 조건은 정상 원본 평가와 분리하고 변형으로 늘어난 행을 새 참가자처럼 취급하지 않는다. 보유 누락·기술 품질·임상적 정보 부족을 서로 다른 상태로 관리한다.


## 9. 품질·누수 방지의 구체 사항

- transcript는 탭 구분으로 읽고 speaker, 시간 순서, 음수·역전 interval을 점검한다.
- Participant 발화에 A/V를 정렬한다. 샘플링률이 다른 자료를 단순 행 번호로 join하지 않는다.
- scrubbed_entry와 대응 0처리 구간은 품질 mask로 제외한다. VUV=0의 F0와 무성 구간의 glottal 특징은 해석하지 않는다.
- COVAREP의 미확정 74번째 열은 사용하지 않는다. 검증한 열만 쓰거나 WAV의 명확한 측정부터 시작한다.
- 시각은 success, confidence 및 -100 등의 sentinel을 점검한다. 원본 영상이 없으므로 사람의 표정 정답과 자동 AU의 일치도를 검증했다고 쓰지 않는다.
- 실패율·기록 길이·question 빈도만의 보조 대조군으로 quality shortcut을 점검한다. 품질 부족을 임상 정보 부족과 동일 라벨로 합치지 않는다.
- feature imputation·scaling·vocabulary·선택은 train 내부. 시험 participant의 전체 기록으로 정규화하면서 가린 정보가 돌아오는 경로를 만들지 않는다.
- K 규칙과 gold 지침이 공유하는 개념은 불가피하지만, 평가자가 모델의 규칙 출력을 보고 gold를 만들면 안 된다. 자연 발생의 모호·부정·시간 변화 사례에서도 성능을 별도 평가한다.

## 10. 해석과 산출물

| 결과 | 가능한 해석 |
|---|---|
| B3가 B2보다 좋고 불필요한 보류가 늘지 않음 | 이 corpus/범위에서 지식 기반 특징의 유용성 지지 |
| D를 넣을 때 해당 근거 판단만 올바르게 전환 | 문맥 의존 정보 처리의 유용성 지지 |
| A/V 추가로 일부 성능 상승, 근거 없는 확인도 증가 | 비언어 통계와 관측 사실을 구분하는 제약 필요 |
| A/V 효과가 작거나 CI가 넓음 | 현재 표본·특징에서 이득 근거가 부족; 일반적 무용성 아님 |
| 삭제 후에도 계속 정보가 있다고 판정 | 정보 잔존, 질문 shortcut, feature leakage 또는 과도한 일반화 점검 |
| 대부분 unknown | 높은 부족 탐지율만으로 성공 처리하지 않음 |

기대 산출물은 annotation 지침, participant manifest, 원본/변형 대응표, 조건별 예측·오류 유형 표, 지표와 CI, 모델·지침·split 버전이다. 참가자 발화와 파생 특징은 `.gitignore`로 보호되는 로컬 영역에 두고 공개 문서는 schema·코드·집계 결과 중심으로 작성한다.

2026-09-27에는 원본 ZIP을 변경하지 않고 다운로드 감사를 수행하고 이 설계를 개정했다. 모델 학습·Notion 쓰기·새 dependency 설치는 하지 않았다. 핵심 잔여 작업은 **424번 다운로드·426/440 재다운로드, 독립 annotation, 품질 mask와 평가 cohort 확정**이다. LLM API 없이 전체 corpus 기반 본실험을 준비할 수 있는 상태와 실험 완료를 구분한다.

설계의 핵심 근거를 이번에 보완 확인한 출처:

- [USC DAIC-WOZ](https://dcapswoz.ict.usc.edu/): 데이터 배포 및 corpus 맥락. 로컬 파일의 실제 보유·split 수는 별도 검사 결과다.
- [Burdisso et al., ClinicalNLP 2024](https://aclanthology.org/2024.clinicalnlp-1.8/): interviewer 질문 shortcut. 질문-only 대조군의 근거.
- [Lenz et al., npj Digital Medicine 2026, PubMed](https://pubmed.ncbi.nlm.nih.gov/42414575/): 세 모의 면담의 정신병리 평가와 정보 부재/과도한 보류 문제. 본 연구와 동일 과제·입력·데이터가 아니다. 이번 출판사 직접 열기는 실패하여 PubMed 및 출판사 검색 결과를 확인했다.
- [NICE NG222](https://www.nice.org.uk/guidance/ng222/chapter/Recommendations): 증상 수 이외 기간·경과·기능 고려. 공식 검색에 반환된 권고 원문 확인; 직접 열기는 실패했다.

Notion이 비교 대상으로 기록한 HiMA-MDD, DepressionAgent, MentalBench 등과의 전체 원문·부록 신규성 검증은 이번 설계의 완료 범위가 아니다. **정보삭제, 멀티모달 결합, 지식 특징 각각을 새로운 기법이라고 주장하지 않는다.** 잠재적 기여는 독립 근거 주석과 정보별 기대 전환, 근거 없는 확인/과도한 보류를 함께 측정하는 작고 재현 가능한 평가 프로토콜이다.
