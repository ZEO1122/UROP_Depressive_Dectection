# DAIC-WOZ 다운로드 검증 — 2026-09-27

## 결론

**아직 전체 다운로드가 정상 완료된 상태는 아니다.** `Data/DAIC-WOZ`에는 참가자 ZIP 188개가 있으나, 정상 ZIP은 186개다. 아래 세 파일을 보완해야 공식 189명 전체를 사용할 수 있다.

| 파일 | 공식 분할 | 확인 결과 | 필요한 조치 |
|---|---|---|---|
| `424_P.zip` | Test | Data 전체 검색에서도 없음 | 다운로드 후 `Data/DAIC-WOZ/`에 저장 |
| `426_P.zip` | Train | 4,194,304 bytes; ZIP 시작 signature는 있으나 종료 directory record 없음, `BadZipFile` | 원 배포처에서 재다운로드 후 재검증 |
| `440_P.zip` | Dev | 619,905,024 bytes; ZIP 시작 signature는 있으나 종료 directory record 없음, `BadZipFile` | 원 배포처에서 재다운로드 후 재검증 |

426/440은 ZIP 중앙 디렉터리를 읽을 수 없어 member CRC 검사를 실행할 수 없었다. 잘린 다운로드와 일치하는 상태지만 실제 전송 실패 원인은 확인하지 않았다. 원본 파일을 삭제·수정·복구하거나 데이터를 다시 다운로드하지 않았다.

## 압축 내용과 무결성 검사

단순 파일명 확인을 넘어 **정상으로 열리는 모든 참가자 ZIP의 모든 member를 끝까지 읽어 CRC를 검사**했다. 참가자 ZIP 점검에는 약 138초가 걸렸다.

- 정상 186개 ZIP의 모든 member CRC: **통과**.
- `documents.zip`, `util.zip`의 모든 member CRC: **통과**.
- 정상 186개 각각에서 다음 필수 **10종** 확인: AUDIO, TRANSCRIPT, COVAREP, FORMANT, CLNF_AUs, CLNF_features, CLNF_features3D, CLNF_gaze, CLNF_hog, CLNF_pose.
- 필수 member 누락, 0-byte member, 중복 member 이름: **0**.
- 487번에는 `._487_TRANSCRIPT.csv`라는 부가 파일이 있어 총 11개 member다. 원래 전사 파일은 별도로 정상 존재한다. 이 부가 파일을 참가자 전사로 읽지 않는다.
- 원본 동영상의 미제공은 기존 DAIC-WOZ 배포 형식과 구분한다. AU·pose·gaze 등 시각 특징이 있다는 것과 원본 영상이 있다는 것은 다르다.

**검증 한계:** CRC는 저장된 ZIP 내부의 무결성 검사다. 원 서버가 공개한 checksum과 대조한 것이 아니므로 원 배포본과 바이트 단위 동일성·진위까지 인증하지 않는다. 모든 feature 값의 임상적 타당성, 전체 시계열 품질, 개인정보 제거의 적정성을 감사한 것도 아니다.

- Train **319**의 `PHQ8_Sleep` 결측, **409**의 released binary와 score≥10 불일치를 재확인했다. 데이터 손상이 아니라 라벨 정책을 명시해야 하는 사항이며 값을 임의 수정하지 않았다.
