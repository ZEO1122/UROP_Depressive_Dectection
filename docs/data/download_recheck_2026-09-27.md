## 추가 발견: ZIP 안에 ZIP이 들어 있음

| 바깥 ZIP | 추가로 들어 있는 파일 |
|---|---|
| `305_P.zip` | `424_P.zip`, `426_P.zip`, `440_P.zip` |
| `429_P.zip` | `426_P.zip` |

중첩 ZIP 5개의 SHA-256을 일반 데이터 폴더의 동명 파일과 대조했으며 **모두 동일한 복사본**이다. 중첩된 440 역시 같은 불완전 파일이므로 복구본이 아니다. 추가 복사본은 약 **2.48 GiB**를 차지한다.

305·429·436의 원래 필수 10종 데이터와 바깥 ZIP CRC는 정상이다. 단, 이는 원 배포 구조와 다른 불필요한 추가 항목이다. 파서는 정확한 참가자 prefix의 필수 10종만 선택하고 ZIP을 재귀적으로 풀어 참가자를 중복 집계하지 않아야 한다. 재다운로드 파일을 옮길 때는 ZIP 내부가 아닌 일반 `Data/DAIC-WOZ` 디렉터리에 저장한다. 이번 감사에서 이 추가 파일을 삭제하거나 ZIP을 수정하지 않았다.

## 실제 검사 범위

- 공식 설명서의 189명 및 로컬 공식 train/dev/test CSV 전체 대조.
- 참가자 ZIP 189개 전수 검사: 열리는 188개 ZIP은 **모든 member를 끝까지 읽어 CRC 검사**. 440은 중앙 디렉터리 파싱 단계에서 실패하여 내부 CRC 검사를 할 수 없음.
- 188명 모두 필수 10종 존재, 빈 member·필수 파일 누락·중복 member 이름 0.
- WAV header와 전사 전체 화자·시간 구간 검사, AU/pose/gaze header 검사.
- `documents.zip`, `util.zip`의 모든 member CRC 통과.
- 검사 중 및 종료 시 파일 크기·수정 시각 불변 확인.
- 참가자 ZIP 합계 **94,600,912,376 bytes (88.10 GiB)**; 불완전 440과 중첩 복사본 포함.
- 전수 ZIP 검사 소요 약 **139초**.

CRC 통과는 ZIP 내부 무결성 검사다. 공식 서버 checksum 대조에 의한 원본 동일성 인증, 모든 feature 값의 타당성 검증, 전체 음성 청취를 수행했다는 뜻은 아니다.
